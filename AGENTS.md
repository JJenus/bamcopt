# Bancopt app (Nuxt 3)

Nuxt 3 SSR app (`nuxt-app`, private). Pages under `pages/` are file-based routes; `middleware/` and `composables/` are auto-imported by Nuxt. Components live in `components/` (plus `components/admin/` and `components/app/`). Nuxt server routes live under `server/`.

## Commands

This repo is **pnpm-only**. `pnpm install` is enforced by the `preinstall` script, and `pnpm-lock.yaml` is the only committed lockfile.

- `pnpm install` — runs `postinstall: nuxt prepare` (generates `.nuxt/tsconfig.json`; `tsconfig.json` extends `./.nuxt/tsconfig.json`)
- `pnpm dev` — `nuxt dev`
  - If you use the self-signed dev certs (`localhost.crt/key`, `server.crt/key`), run with `NODE_TLS_REJECT_UNAUTHORIZED=0`
  - Dev env can be loaded from **`.env.local`** (`nuxt dev --dotenv .env.local`) when that file exists
- `pnpm build` — `nuxt build`
- `pnpm generate` — `nuxt generate`
- `pnpm preview` — `nuxt preview`
- `pnpm test` — end-to-end smoke suite (`tests/smoke.mjs`)
- `pnpm lint:api` — enforces that only `services/` calls the API

## Environment

- `.env.local` is **tracked** in git (`BE_API=http://localhost:8080/api`)
- `.env` and other `.env.*` (except `.env.example`) are gitignored
- `BE_API` default in `nuxt.config.ts` is `https://bancopt.alwaysdata.net/api`
- Do not commit new secrets: `nuxt.config.ts` already contains a hardcoded `CLOUD_SECRETE`, and `server/ff.zx` contains hardcoded credentials/passwords.

## Auth

- Cookie-based auth (`auth` cookie, maxAge 1 day) via the `useAuth()` composable (`composables/authStates.ts`)
- Route guards: `middleware/auth.ts` (user) and `middleware/adminAuth.ts` (admin) — both call `useAuth().logout()` and redirect when unauthenticated / wrong role

## Verification

- `pnpm test` — smoke suite (`tests/smoke.mjs`).
- `pnpm lint:api` — enforces that UI code never calls the API directly.
- **No linter, formatter, ESLint, or CI config** in this repo; there is no `lint` or `typecheck` script.
- TypeScript types come from `.nuxt/tsconfig.json`, regenerated by `nuxt prepare` (runs on `postinstall`).

## Git-ignored build outputs

`.nuxt`, `.output`, `.nitro`, `.cache`, `.data`, `dist`, `node_modules`, `logs`, `.env`.
